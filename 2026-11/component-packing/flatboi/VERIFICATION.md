# What was checked

The product change was implemented by one AI agent (gpt-6.1-sol, xhigh) and examined by a different AI agent (gpt-6.1-sol, high). These are automated experiments and AI review, not a claim that a human used or reviewed the contribution.

The independent check covered the complete saved first-input meshes and raster outputs, and exact comparisons to the separately verified second-input results. It recomputed distances and distortion, reconstructed the native fixed-point raster samples, and checked correspondence to source vertices and faces. The first input's default-off output is byte-identical to the unmodified baseline; its normal product and diagnostic packed outputs are byte-identical. The second input's packed UVs, trace and three XYZ TIFFs are identical to the earlier separately verified packing experiment. SLIM runs before packing; its saved energies and pre-packing coordinates agree between corresponding runs.

For the reported rejection pairs, continuous triangle-interior overlap was also checked. Packing removes the observed cross-component pairs; the remaining one and 356 pairs are within components and have no shared source vertex. This is not an exhaustive search of all possible triangle intersections. The first input's one remaining pair differs from its original same-component pair because translating the UVs changes raster phase.

A low-keep run (1.5%, five iterations, first input) retained all 103 original invalid-UV vertices and 225 omitted faces. This establishes preservation of those flags for that case, not correctness of coarse-to-fine lifting. Small helper checks covered zero or one eligible component (exact no-op), a two-component translation and an isolated vertex. Invalid scale inputs and metadata-write behavior were code-reviewed but not tested end to end.

The independent saved-data check completed in 86.36 seconds with a measured peak of 808,067,072 bytes of RSS. Implementation and verification used sequential processes. The original experimental files are retained in the research repository; their manifests and the independent report/result hashes are identified in [PROVENANCE.json](PROVENANCE.json). The new portable evaluator was then run on five saved cases and reproduced the previously checked scalar counts and distances. Its packaged results are in [results.json](results.json). That packaging check is not an additional independent experiment.

All three packaged patches were applied to isolated, hash-checked source copies. The resulting flatboi and raster source files exactly matched the instrumented sources used in the experiments. Diagnostic patch headers were normalized to repository-relative paths; the product patch was copied unchanged. Linux shell examples were syntax-checked, but the optional diagnostic CMake build instructions have not been independently rebuilt end to end.

Failures are retained in the private experiment record. An initial helper assertion incorrectly required both already-packed components to move; it was corrected to use pre-packing UVs, without changing product code. Packaging encountered a Windows Git ownership refusal on exFAT and then LF-to-CRLF conversion. The final check used hash-checked source copies and per-command `core.autocrlf=false`; no persistent Git safety or line-ending settings were changed.

This package does not establish fiber visibility, ink readability, absence of every within-component overlap, human adoption, compatibility with every upstream version, or eligibility for a prize. It supplies a narrow product option and reproducible evidence on the two named public inputs.
